# User Guide

## Reporting an item
1. Click **Report Lost** or **Report Found** in the navigation bar.
2. Fill in the item name, category, description, date, location and contact details.
3. Optionally attach a photo and submit the form.

## Finding an item
- Open **Items** and use the search box or category filter.
- Open an item to see its details and any possible matches.

## Admin
- Log in from the admin login page to view the dashboard.
- Admins can edit items, delete items and mark them as returned.
